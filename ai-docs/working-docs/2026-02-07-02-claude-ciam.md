# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this directory.

## What This Is

Bash scripts that configure Phase Two (hosted Keycloak) via the Admin REST API. All scripts are idempotent and safe to re-run.

## Commands

```bash
bash scripts/setup-all.sh        # Run all 10 scripts in order
bash test/verify-setup.sh        # Validate setup (37 checks)
bash scripts/09-configure-production-uris.sh  # Add production redirect URIs only
```

## Script Order

1. `00-helpers.sh` — shared functions (sourced, not executed directly)
2. `01-configure-realm.sh` — realm settings, brute force protection
3. `02-configure-user-profile.sh` — custom user attributes (loyalty_tier)
4. `03-configure-social-idps.sh` — Google/Microsoft/Facebook (skips if env vars empty)
5. `04-register-clients.sh` — creates `poc-bff` + `poc-backend` clients
6. `05-configure-token-mappers.sh` — **critical**: maps `organizations` + `loyalty_tier` into JWT
7. `06-create-organizations.sh` — acme-corp (ACC-001), globex-inc (ACC-003)
8. `07-create-org-roles.sh` — admin, billing, viewer per org
9. `08-create-test-users.sh` — admin@test.com, user@test.com, multi@test.com (password: Test1234)
10. `09-configure-production-uris.sh` — adds production redirect URIs (reads `PRODUCTION_APP_URL` from env)

## Key Patterns

**Admin token refresh:** tokens expire in 60s. `get_admin_token()` in helpers caches for 45s and auto-refreshes. Always call it before API batches.

**Helper functions** (`00-helpers.sh`): `kc_get()`, `kc_post()`, `kc_put()`, `get_client_uuid()`, `get_user_id()`, `get_org_id()` — all handle auth automatically.

**Phase Two vs standard Keycloak:** Organizations API uses `/realms/{realm}/orgs/` (not `/admin/realms/`). See `ai-docs/ciam-specification.md` for details.

## Token Mappers (Critical)

`05-configure-token-mappers.sh` determines what claims appear in the JWT. Without correct mappers, the entire security model breaks. Both `organizations` and `loyalty_tier` must appear in access_token and id_token.
